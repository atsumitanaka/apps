# NIMSジュニア勤務表ジェネレータ

NIMSジュニア研究員（Master / Doctor プログラム）の年間勤務日をカレンダー上で組み立てるWebツール。事務局（管理者）が複数学生の勤務表を作成し、共有リンクまたはメールで学生へ配布します。

**公開URL**

| 画面 | URL |
|---|---|
| 管理画面 (JP) | https://atsumitanaka.github.io/apps/nims_junior_schedule/admin/ |
| 管理画面 (EN) | https://atsumitanaka.github.io/apps/nims_junior_schedule/admin/index_en.html |
| 学生ビュー (JP) | https://atsumitanaka.github.io/apps/nims_junior_schedule/#s=… |
| 学生ビュー (EN) | https://atsumitanaka.github.io/apps/nims_junior_schedule/index_en.html#s=… |

学生ビューのURLは管理画面から生成します。

---

## 概要

- **対象:** Master プログラム（月11日 / 年132日）、Doctor プログラム（月14日 / 年168日）
- **原則:** 「任意の連続7日間でちょうど3日勤務」
- **調整月:** 2月・3月・8月・9月 + 前後7日間バッファ（ルール緩和期間）
- **夏季休暇:** NIMS推奨のお盆期間（8/13-16をコアに平日4日）を自動非勤務

---

## 使い方（管理者・事務局）

### 1. 学生を登録する

1. 管理画面（`/admin/`）にアクセスします。
2. 「**+ 学生を追加**」ボタンで新規学生タブを作成します。
3. **名前**・**メール** を入力します。
4. **プログラム**（Master / Doctor）・**開始年月**・**週パターン**（勤務する曜日を最大3つ選択）を設定します。
5. カレンダーが自動生成されます。

複数の学生を同時に管理でき、タブをクリックして切り替えられます。

### 2. カレンダーを調整する

- **日付クリック** で「勤務日（青）↔ 非勤務日（白）」を切り替えます。
- **薄黄色の期間**（調整月・前後バッファ）は週3日ルールの対象外です。自由に設定できます。
- **薄紫の日**（夏季休暇）は自動設定されます。
- **`!` マーク**が出た日は週3日ルール違反 — 赤枠の週を確認して調整してください。
- **「編集リセット」** で手動変更を全て元に戻せます（週パターンは変わりません）。

### 3. 勤務表を共有する

- **「メールで送信」**: メーラーが開き、宛先・件名・共有URL入りの本文が自動入力されます（送信は手動）。
- **「リンクをコピー」**: URLをクリップボードにコピーします。チャット・Teams 等で送付できます。

勤務表を更新した場合は、新しいリンクを再送してください。

### 4. CSV出力

「**CSV出力**」ボタンで年間勤務データ（日付・曜日・勤務日フラグ・調整期間フラグ・祝日名）を Excel/Numbers 用CSVファイルとしてダウンロードできます。

---

## 使い方（学生）

1. 事務局から受け取ったURLをPC/スマホで開きます。
2. カレンダー・週パターン・月別集計が表示されます。
3. 「**CSV出力**」で手元にデータを保存できます。
4. 編集はできません。変更が必要な場合は事務局に連絡し、新しいリンクを再送してもらってください。

---

## カラーと表示ルール

| 色 | 意味 |
|---|---|
| 青 | 勤務日 |
| 薄黄 | 調整期間（週3日ルール対象外・自由設定可） |
| 薄紫 | 夏季休暇（お盆・自動設定） |
| 白 | 非勤務日 |
| 赤枠 + `!` | 週3日ルール違反（要確認） |

- 祝日・夏季休暇を含む7日窓は違反判定対象外
- 調整月（2・3・8・9月）前後7日間バッファも対象外

---

## データの保存と上限

| 項目 | 内容 |
|---|---|
| 保存場所 | ブラウザの localStorage（サーバーへの送信なし） |
| 登録できる学生数 | 上限なし（実質的にはブラウザのストレージ容量 5〜10 MB が限度） |
| 目安 | 数十〜百人規模は問題なく使用可能 |
| データ消去・PC移行時 | 各学生の「リンクをコピー」で共有URLをバックアップとして保管 |

> **注意:** ブラウザのキャッシュ消去・プライベートモード終了・異なるブラウザ使用時はデータが消えます。重要な学生データは必ず共有URLを保管してください。

---

## 技術メモ

- **単一HTML × 4ファイル**（管理JP/EN、学生JP/EN）、ビルド不要・外部依存なし
- **状態管理**: 管理側は `localStorage` (`nims_junior_admin_v1`)、学生側は URL fragment `#s=<base64(JSON)>`
- **メール送信**: `mailto:` プロトコルでローカルのメーラーを起動（Outlook / Apple Mail / Gmail 等）
- **祝日**: 1980〜2099年で有効な近似式（春分・秋分・振替休日・国民の休日を含む）
- **夏季休暇**: 8/13-16をコアに、週末・祝日を除いた平日4日を自動確保

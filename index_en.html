Polymer Composition BigSMILES Input Tool

Generate database-ready JSON by entering polymer repeat units in BigSMILES notation. 26 preset polymers with alias / trade-name search (Noryl, Kapton, etc.). Drop a chemical structure image into the search box and Gemini Vision extracts the SMILES automatically. PubChem lookup for compound-name ⇄ SMILES interconversion, Gemini-driven monomer back-inference, and SmilesDrawer structure preview. New polymers and monomers can be added to the shared DB via Issue Form; a GitHub Actions workflow opens a PR, and after review the entry becomes available to every user. Bonding descriptor is [$] throughout (BigSMILES spec).

Starrydata2 Open Access Filter

A userscript that adds Open Access badges and license labels to Starrydata2 paperlist pages. Full-project scan via the Unpaywall API, CC BY / CC0 filtering, CSV export, and on-demand search by editor (curator) name. Results are cached in IndexedDB for 30 days and scale to 30k-paper projects. Requires the Tampermonkey extension in Chrome / Edge / Firefox — clicking "Install" opens the extension's install prompt.

Starrydata2 Summary Chart Resize

A userscript for the Starrydata2 summary (report) page: makes the Chart.js tiles follow the window width and adds an in-page UI to switch column count (auto / 1–6) and data-point radius (0–12 px). Preferences persist via localStorage.
